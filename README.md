# Digest Archive (GitHub Pages)

- Giornate: `days/YYYY-MM-DD/`
- HTML monofile portatile: `portable/digest-latest.html`, `portable/digest-all.html`
- PDF: `pdfs/<source>/YYYY-MM-DD.pdf`

Published via GitHub Pages from branch `main` (root).
